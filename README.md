# Enhancer VHSRip

Локальная десктопная программа для улучшения роликов из VHSRip и других старых записей: убирает чересстрочность, срезает чёрные поля, подавляет шум, корректирует цвет, увеличивает разрешение нейросетью Real-ESRGAN и восстанавливает лица (CodeFormer или GFPGAN). Видео обрабатывается фрагментами по 5–10 с и склеивается обратно без видимых швов. Всё работает на вашем компьютере, без облака.

Стек: **Electron 45 + Angular 22** (signals, zoneless). Обработку делают **ffmpeg** и **Real-ESRGAN ncnn-vulkan**, которые программа запускает как отдельные процессы.

## Возможности

- **Монтаж** (вкладка «Монтаж», в духе Clipchamp): просмотр, нарезка на клипы по бегунку, удаление лишнего, подрезка краёв клипа мышью или кнопками «Обрезать до/после бегунка», перестановка клипов, отмена и повтор до 5 шагов.
  - **Несколько видео в одном ролике:** «+ Видео» добавляет другое видео из списка или файл с диска после выбранного клипа. Формат ролика (размер, частота кадров) задаёт видео, из которого открыт монтаж; остальные приводятся к нему: другая форма кадра вписывается с чёрными полями, другая частота кадров пересчитывается, у видео без звука подкладывается тишина.
  - **Переходы** между любыми соседними клипами: затемнение, растворение, шторка, сдвиг, от 0.25 до 2 с (кнопка ＋ на стыке, «Применить ко всем стыкам»). При просмотре затемнение видно в плеере, остальные переходы отмечены подписью; точный вид — в результате.
  - **Реверс** (кнопка «⇄ Реверс» или `R`): выбранный клип играет задом наперёд, звук тоже. Если ничего не выбрано, переворачивается весь монтаж: клипы в обратном порядке, каждый с конца, переходы остаются на своих стыках. Повторное нажатие возвращает как было, отменяется через `Ctrl+Z`. В плеере обратное воспроизведение видно сразу (для этого один раз готовится перевёрнутая копия видео для просмотра).
  - **Звук: извлечь и наложить** (блок «Звук» под таймлайном), например для перевода:
    1. «Извлечь звук: WAV / MP3» сохраняет звук монтажа ровно таким, каким он будет после сборки (с нарезкой, переходами и реверсом), рядом с видео: `имя_audio.wav`.
    2. Готовый перевод кладётся обратно кнопкой «+ Наложить аудио»: он встаёт на звуковую дорожку под клипами с позиции бегунка. Блок можно тянуть мышью, сдвигать кнопками ±0.1 с, ставить «с бегунка», менять громкость (до 200%) или удалить.
    3. «Исходный звук: Оставить / Тише (25%) / Выключить» решает, что делать с оригиналом. При первом наложении он сам становится «Тише».

    В плеере наложенный звук играет синхронно с картинкой; при сборке он смешивается с роликом и длится ровно столько же, сколько видео.
  - **Сохраняется сам:** монтаж вместе с историей отмены записывается при каждом изменении. После перезапуска он восстанавливается, когда снова открываешь то же видео, а на главном экране есть список «Продолжить монтаж».
  - **«Смонтировать»:** без потерь (FFV1 + FLAC в MKV, чересстрочность сохраняется, если все клипы из одинаковых видео) — для дальнейшего улучшения; или **MP4** (H.264 + AAC, качество «Высокое» или «Компактное») — чтобы смотреть и делиться. Результат появляется в списке слева.

  Клавиши: `S` разрезать, `R` реверс, `Delete` удалить клип, `Ctrl+Z` / `Ctrl+Y` отменить / повторить, `←` `→` по кадру, `Shift+←` `→` по секунде, пробел играть, `Home` / `End` в начало / в конец, `Esc` закрыть меню.
- **Анализ при добавлении:** разрешение, fps, кодеки, битрейт, чересстрочность (фильтр `idet`) и чёрные поля (`cropdetect`).
- **Очистка:** деинтерлейс `bwdif` (автоматически, если найдена гребёнка), обрезка по краям, три уровня шумоподавления (`hqdn3d` / `nlmeans`).
- **Цвет:** автоматический баланс белого (`grayworld`), яркость, контраст, насыщенность, гамма.
- **Апскейл:**
  - нейросетью: `realesr-animevideov3` (быстро, ×2/×3/×4) или `realesrgan-x4plus` (качественнее, ×4);
  - быстрый режим ffmpeg (lanczos + резкость) без нейросети.
- **Улучшение лиц:** детектор YuNet находит лица на каждом кадре, модель прорисовывает глаза, кожу и черты, а затем лицо вклеивается обратно с мягкой маской. На выбор две модели:
  - **CodeFormer** с ползунком «Похожесть» (fidelity): чем выше, тем больше остаётся от оригинального лица. По умолчанию 0.7;
  - **GFPGAN 1.4:** быстрее, но чаще делает лицо «гладким».

  На Windows работает через ONNX Runtime + DirectML, то есть на видеокартах AMD, Intel и NVIDIA, без Python и CUDA.
- **Фрагменты:** видео режется на куски по 5–10 с: автоматически, по сценам (детектор смены сцены ffmpeg) или вручную на таймлайне с покадровой навигацией. Соседние фрагменты можно объединять, а улучшение лиц включать или выключать для каждого фрагмента отдельно. Каждый фрагмент обрабатывается с запасом соседних кадров, поэтому стыков не видно, а звук берётся из оригинала один раз при склейке.
- **Кэш фрагментов:** готовые фрагменты сохраняются. Если поменять настройки одного фрагмента или прервать обработку, при следующем запуске пересчитается только то, что изменилось. Размер кэша виден в шапке (по умолчанию не больше 10 ГБ, старые фрагменты удаляются сами), его можно очистить.
- **Повтор при сбое:** если фрагмент упал (например, сбой драйвера видеокарты), он пересчитывается ещё до двух раз, а не теряется вся работа.
- **Итоговое разрешение** с сохранением пропорций: 4:3 → 1440×1080, а не растянутые 1920. Режим «Авто» не превышает 1080p и честный предел выбранного масштаба.
- **Превью «до/после»** на фрагменте 2–5 с: обе модели рядом или «шторкой», с оценкой времени на весь клип.
- **Очередь** из нескольких клипов, прогресс, оставшееся время, отмена.
- На выходе **MP4 (H.264 + AAC)** с исходным звуком, рядом с исходником или в выбранной папке.

## Требования

- **Windows 10/11 x64** (основная платформа). Linux и macOS тоже работают, ffmpeg там берётся из системы.
- **Node.js 22+** и npm.
- Видеокарта с поддержкой **Vulkan**. Подходит и встроенная: AMD Radeon 680M/780M/880M, Intel Iris Xe/Arc. CUDA не нужна.

## Установка и запуск

```bash
git clone https://github.com/povezlo2/enhancer-VHSRip.git
cd enhancer-VHSRip
npm install
npm run setup      # скачает Real-ESRGAN, ffmpeg и модели для лиц в bin/ (~1 ГБ)
npm run dev        # режим разработки с автоперезагрузкой
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm start` | собрать и запустить без dev-сервера |
| `npm run dist` | собрать установщик Windows в `release/` |
| `npm run typecheck` | проверить типы Electron и Angular |
| `npm test` | тесты: монтаж и история действий, нарезка, кэш, покадровая точность склейки и монтажа через ffmpeg |
| `npm run setup -- --force` | переустановить инструменты |

## Рекомендуемые настройки для VHSRip

Для типичного исходника вроде XviD 768×576, 25 fps:

1. **Чересстрочность — «Авто»:** программа сама решит, нужен ли `bwdif`.
2. **Обрезка:** примите предложение анализа и при необходимости добавьте 6–10 px снизу, чтобы убрать дрожащую полосу от головки.
3. **Шумоподавление — «Слабое» или «Среднее».** Сильное смазывает детали, которые потом не вытянет и нейросеть.
4. **Модель:** начните с быстрой ×2 и сделайте превью. Если лица выглядят «нарисованными», сравните с x4plus.
5. **Итоговая высота — «Авто» или 1080p.** Для исходников 144–240p честный потолок около ×4 (576–960p).
6. **Лица:** CodeFormer с похожестью 0.6–0.8, сила 40–70%. На 100% лица могут стать «чужими» и слегка мерцать между кадрами. На общих планах с мелкими лицами пользы почти нет: лица меньше ~48 px пропускаются. Удобнее всего нарезать видео по сценам и включить лица только на фрагментах с крупными планами.
7. **Резкость — «Слабая»,** CRF 16.

### Сколько это займёт

На ноутбуке с Radeon 780M (Ryzen 7 8845HS), ориентировочно на 30-секундный клип 768×576 (750 кадров):

| Режим | Время |
|---|---|
| ffmpeg без нейросети | секунды |
| animevideov3 ×2 | ~5–15 мин |
| x4plus ×4 | ~30–60 мин |
| + улучшение лиц | добавляет примерно 0,2–1 с на каждое лицо в кадре |

Работайте от сети и включите режим «Производительность» в MyASUS: на батарее видеокарта сильно замедляется. Точное время покажет превью.

## Как устроено

```
Angular UI ──IPC──> Electron main ──spawn──> ffmpeg       (анализ, сцены, очистка, сборка)
                                  └─spawn──> realesrgan-ncnn-vulkan (апскейл)
                                  └─spawn──> faces/cli.js        (YuNet + CodeFormer/GFPGAN, ONNX Runtime)
```

Конвейер одного клипа:

1. **Нарезка.** Клип делится на фрагменты: заданные в редакторе или автоматически по ≤10 с. Кадр N — это временная позиция `N / fps`. Если в записи есть выпавшие кадры (частая история с захватом VHS), на их месте повторяется предыдущий кадр, как в любом плеере, поэтому звук не уезжает.
2. **Для каждого фрагмента** (готовые берутся из кэша):
   1. **ffmpeg** декодирует фрагмент с запасом в 8 кадров до начала, чтобы временные фильтры `bwdif` и `hqdn3d` «разогрелись», применяет `crop`, шумоподавление и цвет, отбрасывает запас и сохраняет кадры в PNG;
   2. **процессоры** обрабатывают кадры по очереди: Real-ESRGAN, затем (если включено) лица. Лица: YuNet находит их, каждое выравнивается по 5 точкам в кадр 512×512, проходит через CodeFormer или GFPGAN и вклеивается обратно с мягкой маской. Процессоры реализуют общий интерфейс (`electron/processors`), и облачный SeedVR2 встанет туда же. Если процессору нужен контекст соседних кадров, фрагмент берётся с нахлёстом;
   3. **ffmpeg** масштабирует до итогового размера (lanczos), добавляет резкость и кодирует фрагмент в H.264 с постоянным шагом кадров.
3. **Склейка.** Фрагменты соединяются без перекодирования (concat demuxer, `-c copy`), звук берётся из оригинала за тот же отрезок и кодируется в AAC.

Стыки проверены тестом: склейка из фрагментов совпадает с обработкой одним куском бит в бит, а с временными фильтрами отличается на стыках не больше чем на уровне 66 дБ PSNR, то есть невидимо.

Монтаж собирается одной командой ffmpeg: каждый клип вырезается по тем же правилам точного кадра (поиск с запасом, `-copyts`, фильтр `fps`), звук режется по тем же временным меткам (`atrim`). Клип из другого видео приводится к формату ролика (`fps`, `scale` + `pad`, `aresample`), только если отличается. Через `xfade` идут только кадры самих переходов: в FFmpeg 6.1 он пересчитывает цвет в 4:4:4 и обратно, поэтому остальные кадры обходят его и остаются нетронутыми. Звук на переходах сводится `acrossfade`. Если хоть один клип пришлось преобразовать (или результат MP4), чересстрочные видео сначала деинтерлейсятся, иначе поля от разных источников порвались бы. Наложенный звук сдвигается на своё место (`adelay`) и смешивается с исходным (`amix`, `duration=first`, без нормализации, поэтому громкость не «прыгает»), исходный при этом приглушается фильтром `volume`. Для «Извлечь звук» строится тот же граф, но без картинки: видео не декодируется, а результат пишется в WAV (PCM 16 бит) или MP3 192 кбит/с.

Реверс делается кусками по 64 кадра от конца к началу: фильтр `reverse` держит в памяти весь свой вход, и целый клип занял бы гигабайты. Каждый кусок разворачивается (`reverse` + `areverse`) во временный файл без потерь, куски склеиваются без перекодирования, и дальше такой клип собирается как обычный. Чересстрочное видео перед разворотом деинтерлейсится: иначе поля внутри кадра шли бы во времени в неправильном порядке. Тесты проверяют, что кадры вне переходов совпадают с исходником бит в бит, в том числе при перестановке клипов, выпавших кадрах, смешивании двух разных видео и реверсе (развёрнутый клип равен кадрам исходника в обратном порядке).

Временные кадры удаляются сразу после фрагмента. Готовые фрагменты и копии для просмотра хранятся в профиле программы (`%APPDATA%/enhancer-vhsrip/cache` на Windows).

```
electron/   main-процесс: окно, IPC, анализ, фрагменты, процессоры, кэш, очередь
shared/     типы и расчёт геометрии, общие для main и UI
src/app/    Angular: store на сигналах, монтаж, настройки, редактор фрагментов, превью
scripts/    загрузка инструментов, smoke-тест
```

Для работы с ИИ-агентами в репозитории лежит скилл Claude Code [ffmpeg-skill](https://github.com/povezlo2/ffmpeg-skill) (`.claude/skills/ffmpeg-skill`): готовые инструменты FFmpeg для нарезки, анализа и проверки видео. В само приложение он не входит. Нужны Python 3.10+ и FFmpeg 6.1+.

Безопасность окна: `contextIsolation`, `sandbox`, без `nodeIntegration`. Видео в интерфейс отдаются через собственный протокол `media://`, и только те файлы, которые выбрали вы или создала программа.
